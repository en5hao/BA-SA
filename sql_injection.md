# SQL Injection: Атака и защита

## Уязвимый код

```python
query = "SELECT * FROM users WHERE login = '" + login + "' AND pass = '" + password + "'"
```

## Описание атаки

Злоумышленник вводит в поле login строку `' OR '1'='1' --`. Символ `'` закрывает исходную кавычку, `OR '1'='1'` создает всегда истинное условие, а `--` превращает в комментарий остаток запроса (проверку пароля). Запрос возвращает всех пользователей, и злоумышленник получает доступ без пароля.

```sql
SELECT * FROM users WHERE login = '' OR '1'='1' -- ' AND pass = ''
```

## Описание защиты

Правильный код должен использовать **Prepared Statements** (параметризованные запросы). SQL-шаблон с плейсхолдерами (`?`) передается в БД отдельно от данных. Параметры подставляются после компиляции запроса, поэтому любые спецсимволы интерпретируются как обычные строки, а не как исполняемый SQL-код.

## Безопасный код

```python
query = "SELECT * FROM users WHERE login = ? AND pass = ?"
cursor.execute(query, (login, password))
```
