# Gherkin-сценарии для User Story «Поиск книги»

## Сценарий 1: Книга найдена

```gherkin
Given Пользователь находится на странице поиска
When Пользователь вводит в строку поиска "Война и мир" и нажимает на кнопку "Найти"
Then Система выводит книгу "Война и мир"
```

## Сценарий 2: Книга не найдена (есть похожие)

```gherkin
Given Пользователь находится на странице поиска
When Пользователь вводит в строку поиска "Война с саламандрами" и нажимает на кнопку "Найти"
Then Система выводит сообщение "По вашему запросу ничего не найдено. Возможно, вы искали:"
And Система предлагает список книг с похожим названием: "Война миров", "Искусство войны", "Война и мир"
```
