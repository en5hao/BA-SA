## Основные итоги

### 1. Бизнес-цели

- Автоматизировать выставление счетов, уйти от Excel
- Ускорить выставление счетов в 2 раза
- Снизить количество ошибок в ценообразовании
- Уменьшить время контроля со стороны руководителя
- В будущем дать клиентам самостоятельный доступ к счетам и актам

### 2. Целевые метрики (KPI)

| Метрика | Целевое значение |
|---------|------------------|
| Скорость выставления счёта | В 2 раза быстрее (среднее время от начала создания до отправки) |
| Доля счетов, созданных в ЛК | ≥95% через 1 месяц после запуска |
| Время отклика системы | ≤3 секунды на любое действие |
| Ошибки ценообразования | Снижение |

### 3. Роли пользователей

| Роль | Основные права |
|------|----------------|
| Менеджер | Создание счетов, применение скидок (в пределах лимита), просмотр своих документов, история действий (3 дня) |
| Стажёр | Как менеджер, но скидка ≤5%, счета проверяет руководитель |
| Руководитель | Просмотр счетов всех менеджеров, утверждение скидок выше порога, история действий (месяц) |
| Директор | Просмотр всего (без права изменений) |
| Администратор | Заведение пользователей, просмотр логов, настройка |
| Бухгалтер | ЛК не нужен, получает PDF по почте |
| Интегратор | Загрузка прайсов (Excel) |
| Клиент | Не в первом релизе |

### 4. Функциональные требования (первый релиз)

- Вход по логину/паролю, смена пароля, блокировка при попытке взлома (без капчи)
- Дашборд с остатками по часто продаваемым товарам
- Формирование счёта (выбор/добавление клиента, подсветка «давно не покупал», PDF)
- Скидки (3 типа с приоритетами — уточняется)
- Просмотр своих документов (счета, акты)
- История действий (3 дня видит менеджер, месяц видит руководитель)
- Экспорт в Excel (автоматическая выгрузка раз в день на почту)
- Сохранение настроек интерфейса
- Мобильная версия (через браузер)
- Интеграция с 1С и Excel (загрузка прайсов)

### 5. Ограничения и исключения (не делаем в первом релизе)

- Доступ для клиентов
- ЛК для бухгалтера (только PDF)
- Полноценный ЛК для курьера (только отдельный экран)
- Авторизация через соцсети / Госуслуги
- Самостоятельная регистрация (только админ)
- Восстановление пароля через SMS (нет бюджета)
- Капча при входе
- Лишние подтверждения
- Чат внутри ЛК
- Календарь встреч

### 6. Технические ограничения

- Интернет в офисе нестабильный
- Сервер старый
- Нет бюджета на дорогостоящую оптимизацию
- 1С старая (возможно обновление)

### 7. Нормативные требования

- 152-ФЗ «О персональных данных» — необходимо соблюдать (ответственность на аналитике/разработке)

### 8. Предположения (допущения)

| Допущение | Временное решение |
|-----------|-------------------|
| Данные о стаже отсутствуют | Константа 1 год для всех менеджеров |
| Паролей нет | Временный пароль 123 |
| Почта есть не у всех | Восстановление пароля через звонок админу |
| Бухгалтер не заходит в ЛК | PDF на почту |
| Планы продаж отсутствуют | Будут предоставлены позже |
| Приоритеты скидок неизвестны | Будут предоставлены позже |

### 9. Бизнес-риски

| Риск | Вероятность | Влияние | Мера снижения |
|------|-------------|---------|----------------|
| Менеджеры продолжат работать в Excel | Средняя | Высокое | Обучение, контроль, удобство ЛК |
| Превышение лимита времени отклика (>3 сек) | Высокая | Критическое | Очередь запросов, кэш |
| Нет данных о стаже | Высокая | Среднее | Константа 1 год |
| Интеграция со старой 1С | Средняя | Высокое | Привлечение разработчиков 1С |
